# Proyecto Ventas — Generación y clasificación de datos

Proyecto Conceptos Fundamentales de Programación
Politécnico Grancolombiano

Requisitos
- Java 8
- Maven

Ejecución
1. Ejecutar la clase `Data_Gen.GenerateInfoFiles` para generar
   los archivos planos de prueba.
2. Ejecutar la clase principal para generar los reportes de
   vendedores y productos.

Estructura
- `Model`: clases de dominio (Vendedor, Producto, Venta)
- `Logic`: reglas de negocio y cálculo de reportes
- `Persistence`: lectura y escritura de archivos
- `Data_Gen`: generación de archivos pseudoaleatorios
- `UI`: interfaz de usuario
